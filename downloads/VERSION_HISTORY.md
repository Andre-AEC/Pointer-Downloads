# Pointer by AEC Simple — Version History

## Version 0.1.2

- Added an in-app Help window with the installed version in its header, plus links to the User Guide and Version History.
- Added an uninstall entry in Windows Installed apps and Programs and Features.
- Changed the default open/close shortcut to **Ctrl+Alt+H** and added a **No Shortcut** choice. Existing custom shortcuts remain saved.
- Fixed **Minimize on manual open** so an unchecked setting keeps the window visible when you open Pointer yourself. Sharing monitor launches still start minimized.

## Version 0.1.1

- Bundled the .NET Desktop Runtime in the Windows installer, removing the separate runtime setup step.

## Version 0.1.0

- Initial Windows release with the pointer circle and click ripples.
- Added adjustable circle size, transparency, and colors, with settings that save automatically.
- Added a customizable shortcut and experimental Teams/Zoom screen sharing monitor.
- Added a Windows installer and Start menu shortcuts. This release required a separate .NET Desktop Runtime installation.

See the [User Guide](USER_GUIDE.md) for installation and use.
